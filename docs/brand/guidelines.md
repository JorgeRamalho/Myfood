# Brand guidelines — MyFood

## Marca
- **Nome:** MyFood
- **Slogan:** O sabor que vem até você.
- **Tagline:** Peça. Saboreie. Repita.

## Assets (fonte da verdade)
Todos os arquivos oficiais ficam em `frontend/public/brand/`:

| Arquivo | Uso |
|---|---|
| `logo-mark.png` | Ícone / favicon / avatar de marca |
| `wordmark.png` | Nome tipográfico |
| `hero-food.png` | Hero full-bleed |
| `client-avatar.png` | Placeholder de perfil |

Não duplique PNGs fora de `public/brand/`. No build Vite, esses arquivos vão para a raiz de `dist-site/`.

Mídia do carrossel: `frontend/public/media/carousel/`.

## Paleta

| Token | Hex | Uso |
|---|---|---|
| Tomato | `#E0311F` | Primária / CTA |
| Cherry | `#9B1B1F` | Gradiente profundo |
| Teal (texto) | `#0F766E` | Links / status sobre fundo claro (WCAG AA) |
| Teal (fill) | `#0D9488` | Gradientes / botões com texto branco |
| Amber | `#F59E0B` | Avaliações |
| Ink | `#141414` | Texto |
| Mist | `#F7F6F4` | Fundo |
| Blush | `#FFE4DC` | Superfícies suaves |

## Tipografia
- **Display (marca):** Syne
- **Títulos:** Sora
- **Corpo / UI:** Figtree

## Composição do first viewport
1. Marca (H1 MyFood) em hero full-bleed  
2. Um slogan curto  
3. Um grupo de CTAs  
4. Imagem hero dominante  

Não colocar carrossel, stats ou listas no primeiro viewport.
